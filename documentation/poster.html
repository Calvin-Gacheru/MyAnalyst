MyAnalyst: An Autonomous Data Analyst Agent

Proof of Concept: Bridging the Gap Between Messy Data and Prescriptive Business Insights

1. Background

The "Blank Stare" Problem: Data analysis is traditionally hindered by a steep technical barrier. Non-technical stakeholders struggle to extract answers without writing Python code, while analysts spend hours on repetitive data cleaning tasks (formatting dates, fixing skewed distributions, stripping currency symbols).

There is a critical need for an accessible tool that eliminates the data science learning curve by handling both the deterministic grunt work and the dynamic generation of business insights.

2. What We Have Built (PoC)

We developed a "junior data scientist that lives on your computer." MyAnalyst is an autonomous, LangGraph-driven data analysis platform served via FastAPI.

  • Automated Data Cleaning: Instantly turns raw, messy CSVs into analytics-ready data structures.
  • Proactive Dashboarding: Generates baseline EDA charts and time-series forecasts before the user even asks a question.
  • Conversational Interface: Allows users to ask natural-language questions, triggering the agent to plan, code, and execute custom Python scripts.
  • Persistent Memory: Learns business rules (e.g., "ignore refunded items") and applies them to all future interactions.

3. Technical Methodology

A. Deterministic Ingestion & Remediation

Before LLM intervention, strict Python heuristics process the data safely and predictably:

  • Regex Parsing: Strips currency/percentages and coerces datetime columns.
  • Noise Reduction: Drops zero-variance columns and flags high-cardinality IDs (UUIDs).
  • Imputation: Replaces missing values via Mean (normal), Median (skewed), or Mode (categorical).
  • Outlier Control: Caps extreme spikes using Interquartile Range (IQR) bounds.

B. Proactive EDA & Autonomous Forecasting

The agent builds an immediate visual baseline:

  • Chart Selection: Dynamically generates histograms, box plots, and scatter plots based on column data types.
  • Smart Forecasting: Evaluates dataset frequency to route to optimal statistical models: Prophet for irregular/high-frequency data, and Auto-ARIMA (SARIMA) for structured, periodic data via AIC grid search.

C. The Self-Correcting Q&A Loop (LangGraph State Machine)

1. Planner Node
Retrieves context & maps logic
→
2. Coder Node
Writes Pandas/Plotly Python
→
3. Sandbox Executor
Runs code in Docker container
→
4. Summarizer Node
Translates output to business advice

* Error Correction Loop: If Step 3 fails, detailed traceback logs route back to Step 2 for autonomous repair (Max 3 retries).

4. Proof of Concept: Test Results & Validation

Secure Execution Architecture

Successfully migrated from native Python exec() to a network-isolated Docker SDK sandbox. Resolved scope limitations (e.g., list comprehension bugs) and implemented hard memory limits (OOM killed) to handle untrusted code safely.

Autonomous Error Correction

The LangGraph router successfully parses Python tracebacks. When syntax or variable name errors occur in generated code, the agent dynamically self-corrects and executes the fixed script without user intervention.

Dynamic Forecasting Engine

Validated against synthetic datasets: the pipeline successfully routes irregular/daily data with dropped rows to Prophet, while routing strict monthly financial metrics to Auto-ARIMA.

Contextual Narrative Generation

Eliminated LLM "blind spots" by extracting DataFrame insights (means, categoric modes, time-series trends) and injecting them into prompts, allowing the AI to generate highly accurate, plain-English business recommendations.
